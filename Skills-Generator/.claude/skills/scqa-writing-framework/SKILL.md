# SCQA Writing Framework

## Overview

This skill helps users structure their writing or presentations using the SCQA framework. It's ideal for crafting compelling narratives that clearly present a problem and offer a solution, suitable for business communication, consulting, and content creation.

**Keywords**: SCQA, writing, framework, communication, problem-solving, storytelling, business, consulting, content creation

## Core Framework

### Situation
- Define the current state or background.
- Set the context for the audience.

### Complication
- Introduce a problem or challenge.
- Disrupt the existing situation to create tension.

### Question
- Pose a key question that arises from the complication.
- Focus the audience's attention on what needs to be resolved.

### Answer
- Provide a solution or recommendation.
- Resolve the question logically and effectively.

## Features

- Generates content structured with Situation, Complication, Question, and Answer elements.
- Provides a logical flow for persuasive communication.

## Output Format

- The output will be structured content, with each section clearly delineated as Situation, Complication, Question, and Answer.

## Instructions

- Provide the necessary context and background information for the Situation section.
- Clearly define the problem or challenge in the Complication section.

## Constraints

- The skill is designed to provide structure and may require user input for specific details and context.
- The generated content is a starting point and may need further refinement.
