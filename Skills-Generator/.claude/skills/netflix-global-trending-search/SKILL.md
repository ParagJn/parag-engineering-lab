# Netflix Global Trending Search

## Overview

This skill searches for the current top 10 Netflix shows that are trending globally and provides comprehensive analysis including ratings, genres, release information, and popularity metrics. Designed for entertainment enthusiasts, content creators, and market researchers who need current Netflix trending data.

**Keywords**: netflix, trending, global, shows, entertainment, streaming, analysis, rankings

## Core Framework

### Data Collection
- Identify current top 10 globally trending Netflix shows
- Gather show metadata including title, genre, release date, and ratings
- Collect popularity metrics and regional performance data

### Content Analysis
- Analyze show descriptions and key themes
- Identify trending genres and content patterns
- Compare current trends with historical data when available

## Features

- Real-time global Netflix trending show identification
- Comprehensive show details including cast, genre, and ratings
- Trend analysis and pattern recognition
- Regional popularity comparisons
- Release date and season information
- Critical and audience rating aggregation

## Output Format

- Numbered list (1-10) of trending shows
- Each entry includes: Title, Genre, Release Year, Rating, Brief Description
- Summary of trending patterns and notable insights
- Data timestamp and regional scope clarification

## Instructions

- Search for the most current Netflix global trending data
- Rank shows 1-10 based on current global popularity
- Include IMDB/Rotten Tomatoes ratings when available
- Provide 2-3 sentence descriptions for each show
- Highlight any notable trends in genres or content types
- Specify data collection timeframe and methodology

## Constraints

- Focus only on Netflix original and licensed content
- Use global trending data, not region-specific
- Limit to current/active trending shows only
- Exclude movies unless specifically requested
- Provide disclaimer about data freshness and source limitations
- Maintain objective, factual tone without personal recommendations
