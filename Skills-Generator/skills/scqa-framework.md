# SCQA Framework

## Overview

This skill leverages the SCQA framework to structure content for clarity and impact. It's ideal for crafting compelling narratives, business writing, and presentations that effectively communicate complex ideas by establishing context, identifying a problem, posing a question, and providing a clear answer.

**Keywords**: SCQA, writing, framework, communication, storytelling, business writing, consulting

## Core Framework

### Situation
- Set the context and background.
- Establish the current state that the audience can understand.

### Complication
- Introduce a problem, tension, or challenge.
- Disrupt the established situation to create interest.

### Question
- Pose a key question that arises from the complication.
- Focus the audience on what needs to be answered.

### Answer
- Provide a solution, insight, or recommendation.
- Logically resolve the question.

## Features

- Generates structured content following the SCQA framework.
- Ensures clarity and logical flow in communication.

## Output Format

- Output will consist of a structured text using the SCQA framework: Situation, Complication, Question, and Answer. Each section will contain a brief description or the answer, depending on the prompt's goal.

## Instructions

- Clearly state the topic you want to address using the SCQA framework.
- Provide sufficient context for the model to understand the situation and potential complications.

## Constraints

- The output should maintain a logical and coherent flow between the S, C, Q, and A.
- The Answer should directly address the Question raised in the framework.
